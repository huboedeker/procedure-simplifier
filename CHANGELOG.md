# Changelog

## 0.8.0 — 2026-11-10

- Package the agent-operated framework as a GitLab-ready Python project with MIT licensing, bundled framework assets, unified CLI, wheel/sdist and build-only CI.
- Replace document-dependent regression fixtures with first-party synthetic data. Exclude real source documents, case histories, screenshots and personal workspace paths.
- Add portable documentation, JSON Schema contracts, installed-package/export checks and distribution inspection.
- Preserve the existing validators and explicit limits: no autonomous model dispatch, automatic PDF ingestion or semantic/adoption certification.

## Pre-repository development

The framework evolved through local workflow, auditing, task switches, visual consistency, source/semantic evidence, closeout/learning, chunk planning and reproducible-metrics/frozen-review improvements. Those experiments are separate local evidence. This release does not republish their private source content or relabel their records as0.8.0 runs.
